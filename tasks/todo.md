# TellMeWeather 改善計画

## 目的
- 明日以降の天気予報をより正確に把握できるようにする
- ユーザの確認手間を最小化する

## 実装機能

### Feature 1: 時間帯別予報 + 降雨タイムライン + 服装強化
- [x] Open-Meteo API に hourly パラメータ追加 (weather.js)
- [x] 新コンポーネント components/hourly.js 作成
  - 時間帯別予報（早朝/朝/昼前/昼過ぎ/夕方/夜）
  - 降雨タイムライン（何時から何時まで雨か可視化）
  - 自然言語サマリー生成（「朝は曇り、昼から雨」）
- [x] 服装アドバイス強化 (clothes.js)
  - 朝の気温 vs 昼の気温差を反映
  - 「朝は肌寒いので上着を」等の具体的アドバイス
- [x] app.js で新コンポーネント結線
- [x] index.html に script タグ追加
- [x] style.css に時間帯別・タイムライン用スタイル追加

### Feature 2: PWA 対応 + 自動更新
- [x] manifest.json 作成（アプリ名、テーマカラー、アイコン設定）
- [x] sw.js サービスワーカー作成（オフラインキャッシュ）
- [x] index.html に PWA メタタグ + SW 登録スクリプト追加
- [x] app.js にページ可視性変更時の自動更新ロジック追加

## 設計方針
- Vanilla JS 維持（依存ゼロ）
- 既存機能の後方互換性を保持
- モバイルファースト
- Open-Meteo API の無料枠内で完結
